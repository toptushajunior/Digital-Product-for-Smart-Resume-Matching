# Digital-Product-for-Smart-Resume-Matching

### 📋 Описание
Цифровой продукт для интеллектуального подбора релевантных резюме. Система автоматически ранжирует кандидатов на основе семантического сопоставления описания вакансии и резюме с использованием методов NLP и больших языковых моделей.

### 🎯 Цель проекта
Разработка MVP цифрового приложения, которое принимает на вход описание вакансии и выдает ранжированный список наиболее подходящих кандидатов из IT-сферы.

### 📊 Датасет
- **Объем**: 2388 резюме 
- **Признаки**: 13 параметров
- **Специфика**: русскоязычные резюме IT-специалистов

### 📄 Описание признаков

| Столбец | Тип данных | Описание | Пример |
|---------|------------|----------|--------|
| `id` | string | Уникальный идентификатор резюме | `4bb539da00018813240039ed1f465662593138` |
| `title` | string | Должность/позиция соискателя | `Python Developer`, `Data Scientist` |
| `city` | string | Город проживания | `Москва`, `Санкт-Петербург`, `Алматы` |
| `age` | int | Возраст кандидата | `25`, `35`, `45` |
| `gender` | string | Пол | `Мужчина`, `Женщина` |
| `area` | string | Сфера деятельности / специализация | `Программист, разработчик`, `Аналитик` |
| `desired_wage` | int/float | Ожидаемая заработная плата (в рублях) | `100000`, `250000`, `450000` |
| `work_experience` | float | Общий опыт работы (в годах) | `2.2`, `5.4`, `10.8` |
| `work_exp_descr` | dict | Описание опыта работы (компания → должность → обязанности) | `{'Яндекс': ['Backend Developer', 'Разработка API...']}` |
| `education_level` | string | Уровень образования | `Высшее образование`, `Неоконченное высшее` |
| `university` | list | Учебные заведения | `['МГУ им. Ломоносова', 'НИУ ВШЭ']` |
| `faculty` | list | Факультеты / направления подготовки | `['ФКН', 'Прикладная математика']` |
| `languages` | dict | Владение языками (язык → уровень) | `{'Русский': 'Родной', 'Английский': 'B2'}` |
| `skills` | list | Профессиональные навыки и технологии | `['Python', 'SQL', 'Git', 'Docker']` |
